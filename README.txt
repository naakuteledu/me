LOVE QR REEL PROJECT - UPDATED
===============================

The website now has this flow:

1. "Do you love me?"
   - NO is rejected.
   - YES continues.

2. "How much do you love me?"
   - Slider from 0 to 100.
   - Face becomes happier as the number increases.
   - Continue is locked until 100%.

3. "Do you want to continue?"
   - She must press YES exactly 100 times.

4. Your apology message appears.

5. Final page.

The apology currently says:

"Hey Chaitra,

I'm really sorry for not being myself and for not treating you properly these past two days..."

You can change this in index.html.

----------------------------------------
RUN ON YOUR PC
----------------------------------------

Double-click:

run.bat

Then open:

http://127.0.0.1:8000/

The QR generated by this project works on your local
Wi-Fi only.

----------------------------------------
IMPORTANT: MAKE IT ACCESSIBLE TO HER
----------------------------------------

For her to open it from another location, the website
must be hosted on the internet.

The easiest beginner method is GitHub Pages:

1. Create/login to a GitHub account.
2. Create a NEW PUBLIC repository.
3. Upload:
   index.html
   style.css
   script.js

4. In the repository:
   Settings -> Pages

5. Select:
   Deploy from a branch
   Branch: main
   Folder: / (root)

6. Save.

GitHub will give you a public HTTPS address similar to:

https://YOURNAME.github.io/REPOSITORY/

That is the address to put into generate_qr.py.

For example, change:

URL = "https://YOURNAME.github.io/REPOSITORY/"

Then run:

python generate_qr.py

The new love_qr.png can be sent to her.

----------------------------------------
NOTE
----------------------------------------

Do NOT use the local address:

http://127.0.0.1:8000/

or:

http://192.168.x.x:8000/

for her unless she is on the same network as your PC.

Use the HTTPS GitHub Pages address for a permanent
shareable QR.
